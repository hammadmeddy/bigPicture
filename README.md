# Interview Starter

Clean Next.js App Router starter for frontend interviews (Figma → responsive UI).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## Commands

```bash
npm run dev    # http://localhost:3000
npm run build  # production build
npm run lint   # ESLint
npm start      # run production build
```

## Structure

```
app/                 # routes, layout, global styles
components/
  layout/            # Header, Footer
  sections/          # Hero, Features, CTA placeholders
  ui/                # Button, Container
lib/utils.ts         # shared helpers (cn)
public/images|icons  # static assets for next/image
```
